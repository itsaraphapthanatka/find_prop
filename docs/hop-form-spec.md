## ภาพรวม

สไลด์นี้เป็น spec **ฟอร์มลงทรัพย์แบบ wizard 5 ขั้น** ไม่ใช่ requirement ฟีเจอร์ทั้งระบบ
สาระสำคัญ 2 อย่าง:

1. ฟอร์มเดิม (เลื่อนยาวหน้าเดียว) ต้องแบ่งเป็น **STEP 1–5**
2. ขยายชุดฟิลด์ให้ครบ **4 หมวดทรัพย์** — เดิม [requirement.md](../requirement.md) มีแค่ บ้าน / คอนโด / ที่ดินเปล่า สไลด์นี้เพิ่ม **เชิงพาณิชย์** และ **เชิงอุตสาหกรรม** เข้ามา

```
STEP 1 ประเภททรัพย์ → STEP 2 ที่ตั้ง → STEP 3 รายละเอียด → STEP 4 ราคา → STEP 5 ลงภาพ
                                          (แตกตามหมวด)
```

## โครงสร้างประเภททรัพย์ (2 ระดับ)

| หมวด | ประเภทย่อย | หน้ารายละเอียดในสไลด์ |
|---|---|---|
| 2.1 ที่อยู่อาศัย | บ้านเดี่ยว, บ้านแฝด, ทาวน์เฮ้าส์, ทาวน์โฮม, คอนโด | "ที่อยู่อาศัยบ้าน", "ที่อยู่อาศัยคอนโด" |
| 2.2 เชิงพาณิชย์ | โชว์รูม, ออฟฟิศ, โฮมออฟฟิศ | "เชิงพาณิชย์ออฟฟิศ", "เชิงพาณิชย์โฮมออฟฟิศ" (โชว์รูมไม่มีหน้า) |
| 2.3 เชิงอุตสาหกรรม | โกดัง, โรงงาน | "เชิงอุตสาหกรรมโกดัง", "เชิงอุตสาหกรรมโรงงาน" (แยกหน้า) |
| 2.4 ที่ดิน | — | "ที่ดิน" |

ปัจจุบันแอปเก็บเป็น list เดียวแบน 8 ค่า

## STEP 1 — ประเภททรัพย์

| # | ฟิลด์ | ตัวเลือก |
|---|---|---|
| 1 | ว/ด/ป | date (default วันนี้) |
| 2 | ประเภททรัพย์ | ตามตาราง 2 ระดับด้านบน |
| 3 | สำหรับ | เช่า / ขาย / เช่า-ขาย |
| 4 | ประเภทสัญญา | **ปิด / เปิด** |
| 5 | สถานะผู้ติดต่อ | **เจ้าของ / เอเจนต์** |
| 6 | รูปแบบผู้ติดต่อ | **บุคคล / นิติบุคคล** |
| 7 | ชื่อและเบอร์โทร | text + tel |

**เพิ่มเฉพาะกรณีขาย** — ค่าใช้จ่ายวันโอนกรรมสิทธิ์: ผู้ขาย 100% / 50-50 / ผู้ซื้อ 100%
**เพิ่มเฉพาะกรณีเช่า** — เงินประกัน, ค่าเช่าล่วงหน้า, ระยะเวลาสัญญา

## STEP 2 — ที่ตั้ง

ชื่อโครงการ · จังหวัด · เขต · แขวง · พื้นที่สี · ปักหมุด · ละลอง (= ละติจูด/ลองจิจูด, ต้องยืนยัน)

**เพิ่มเฉพาะหมวดอุตสาหกรรม** — เขต:
- ปลอดอากร (Free Zone)
- การนิคมอุตสาหกรรม (กนอ.)
- วัตถุอันตราย (DG Zone)

## STEP 3 — รายละเอียด (แตกตามหมวด)

### ที่อยู่อาศัย — บ้าน
หันหน้าทิศ · พื้นที่ดิน (**ไร่ / งาน / ตารางวา** แยกช่อง) · พื้นที่ใช้สอย (ตร.ม.) · จำนวนชั้น 1–5 · ห้องนอน 1–5 · ห้องน้ำ 1–5 · ห้องครัว · ห้องแม่บ้าน 1–5 (ถ้ามี) · ที่จอดรถ · พื้นที่ส่วนกลาง (สวน, สระว่ายน้ำ — กรณีโครงการจัดสรร) · เครื่องใช้ไฟฟ้า (แอร์ **กี่เครื่อง**, เครื่องทำน้ำอุ่น **กี่เครื่อง**, อื่นๆ) · เฟอร์นิเจอร์ (มี / บ้านเปล่า) · เลขที่โฉนด · เอกสารสิทธิ์ (สำเนาโฉนดหน้า-หลัง **\*ต้องมี**) · ค่าสาธารณูปโภค · ตั้งอยู่ใกล้

**ค่าสาธารณูปโภค** — แต่ละรายการมี *ราคาต่อหน่วย* + **ชำระกับใคร**:
- ค่าน้ำ → ราคาต่อหน่วย + ชำระการประปา
- ค่าไฟ → ราคาต่อหน่วย + ชำระการไฟฟ้า
- ค่าส่วนกลางและเก็บขยะ → ราคาต่อหน่วย + ชำระกับหน่วยงานที่เกี่ยวข้อง

### ที่อยู่อาศัย — คอนโด
ประเภทคอนโด (studio / duplex) · ห้องนอน (1 / 2) · ห้องน้ำ · ห้องครัว · พื้นที่ใช้สอย · ระเบียงหันทิศ (เหนือ/ใต้/ตะวันออก/ตะวันตก/อื่นๆ) · ห้องอยู่อาคารไหน · ห้องอยู่ชั้นที่ · ตึกสูงกี่ชั้น · โครงการมีกี่ตึก · พื้นที่ส่วนกลาง (สวน, สระ, ฟิตเนส, อื่นๆ) · เครื่องใช้ไฟฟ้า (แอร์, เครื่องทำน้ำอุ่น, ตู้เย็น, เครื่องซักผ้า, อื่นๆ — ระบุจำนวน) · เฟอร์นิเจอร์ (มี / ห้องเปล่า) · เอกสารสิทธิ์ (สำเนาโฉนด/ใบ อ.ช.2 หน้า-หลัง **\*ต้องมี**) · ตั้งอยู่ใกล้

> สไลด์เขียน "จำนวนห้องน้ำ - 1-5 **ชั้น**" — น่าจะพิมพ์ผิดจาก "ห้อง"

### เชิงพาณิชย์ — ออฟฟิศ
ขนาดออฟฟิศรวม (ตร.ม.) · **จำนวนห้อง** 1–5 / ไม่มี · อยู่ชั้นที่ · ตึกสูงกี่ชั้น · โครงการมีกี่ตึก · **ความสูงของเพดาน** · จำนวนที่จอดรถ · เฟอร์นิเจอร์ (มี / ห้องเปล่า) · ตั้งอยู่ใกล้ · พื้นที่ส่วนกลาง (สวน, สระ, ฟิตเนส, อื่นๆ) · เครื่องใช้ไฟฟ้าในห้อง

### เชิงพาณิชย์ — โฮมออฟฟิศ
ขนาดออฟฟิศรวม (ตร.ม. + **กว้าง x ลึก**) · จำนวนชั้น 1–5 · จำนวนห้อง 1–5 · จำนวนห้องน้ำ 1–5 · ห้องครัว · โครงการมีกี่ตึก · ความสูงของเพดาน · จำนวนที่จอดรถ · เฟอร์นิเจอร์ · ตั้งอยู่ใกล้ · พื้นที่ส่วนกลาง · เครื่องใช้ไฟฟ้าในห้อง

### เชิงอุตสาหกรรม — โกดัง
พื้นที่ดิน (ไร่/งาน/ตร.ว.) · ขนาดอาคารรวม (ตร.ม.) · ขนาดโกดัง (ตร.ม. + กว้าง x ลึก) · จำนวนชั้นออฟฟิศ 1–5 · ขนาดออฟฟิศรวม · ความสูงอาคาร · **พื้นอาคารยกสูง (ซม.)** · รับน้ำหนัก (ตัน) · จำนวนประตู (บาน + กว้าง x สูง) · ระบบไฟฟ้า · จำนวนที่จอดรถ · มีเครน (ใช่/ไม่) · ใกล้ถนนหลัก (ใช่/ไม่) · อาคารเดี่ยว (ใช่/ไม่) · รถตู้คอนเทนเนอร์เข้าได้ (ใช่/ไม่) · ตั้งอยู่ใกล้

### เชิงอุตสาหกรรม — โรงงาน
เหมือนโกดังทุกข้อ **+ เพิ่ม**: จำนวนน้ำที่ใช้ได้ต่อวัน · **บ่อบำบัดน้ำเสีย (มี/ไม่มี)**

### ที่ดิน
พื้นที่ดิน (ไร่/งาน/ตร.ว.) · ใช้ประโยชน์อะไรได้บ้าง · FAR · ขอบเขตติดถนนสาธารณะ (ไม่ติด / ติด 1 ด้าน / ติด 2 ด้าน / อื่นๆ) · ถนนสาธารณะกว้างกี่เมตร · มีไฟฟ้า/น้ำประปาผ่านแปลงไหม · **อยู่ใกล้สถานที่สำคัญ + ระยะกี่กิโลเมตร** (โรงพยาบาล, โรงเรียน, ตลาดสด, ห้างสรรพสินค้า, อื่นๆ)

> สไลด์หน้าที่ดินไม่ได้ระบุ OSR (ที่ [requirement.md](../requirement.md) มี) — คงฟิลด์ `osr_ratio` เดิมไว้

## STEP 4 — ราคา

ราคารวม · ราคาต่อ ตร.ม.
**ใส่แค่กรณีเช่าหมด (ยกเว้นที่อยู่อาศัย)**: ภาษีที่ดิน · หัก ณ ที่จ่าย · **VAT**

## STEP 5 — ลงภาพ

รูปถ่าย (แอปรองรับ 10 รูปแล้ว) + วิดีโอ + "เพิ่มไฟล์" (เอกสารสิทธิ์ — อยู่ใน STEP 3 ของสไลด์)

## Gap analysis

### ก. ฟิลด์ใหม่ที่ต้องเพิ่มใน DB (ยังไม่มีเลย)

| ฟิลด์ในสไลด์ | เสนอชื่อคอลัมน์ | STEP |
|---|---|---|
| ประเภทสัญญา — ปิด / เปิด | `agreement_type text` | 1 |
| รูปแบบผู้ติดต่อ — บุคคล / นิติบุคคล | `contact_form text` | 1 |
| VAT | `vat text` | 4 |
| หันหน้าทิศ (บ้าน) | `house_direction text` | 3 |
| พื้นที่ดิน แยก ไร่ / งาน / ตร.ว. | `land_rai`, `land_ngan`, `land_wa numeric` | 3 |
| ความสูงเพดาน / ความสูงอาคารต่อชั้น | `ceiling_height`, `floor_height numeric` | 3 |
| พื้นอาคารยกสูง (ซม.) | `floor_raise_cm numeric` | 3 |
| จำนวนห้อง (ออฟฟิศ / โฮมออฟฟิศ) | `rooms numeric` | 3 |
| บ่อบำบัดน้ำเสีย (โรงงาน) | `wastewater_pond text` | 3 |
| "ชำระกับใคร" ต่อค่าน้ำ / ค่าไฟ / ส่วนกลาง | `water_payee`, `power_payee`, `common_fee_payee text` | 3 |
| ตั้งอยู่ใกล้ + ระยะกิโลเมตรต่อสถานที่ | `nearby_places jsonb` | 2–3 |

### ข. ฟิลด์ที่มีแล้วแต่รูปแบบไม่ตรง

- **สถานะผู้ติดต่อ** — แอปมี `lessor_status = บุคคล/บริษัท` แต่สไลด์แยกเป็น 2 คำถาม (เจ้าของ/เอเจนต์ + บุคคล/นิติบุคคล) → ต้อง migrate ค่าเดิมไป `contact_form` แล้วให้ `lessor_status` เก็บ เจ้าของ/เอเจนต์
- **โซนอุตสาหกรรม** — `zones` มีแค่ `['เขตปลอดอากร']` → ต้องเป็น 3 ตัวเลือก (Free Zone / กนอ. / DG Zone) และแสดงเฉพาะหมวดอุตสาหกรรม
- **สเปกโกดัง/โรงงาน** — เครน, ใกล้ถนนหลัก, อาคารเดี่ยว, รถคอนเทนเนอร์เข้าได้ ปัจจุบันเป็น string ใน `features[]` แต่สไลด์ระบุเป็น ใช่/ไม่ ต่อข้อ → ถ้าต้องการ filter แม่นควรแยกเป็น boolean (บ่อบำบัดยังไม่มีทั้งสองแบบ)
- **พื้นที่ส่วนกลาง** (สวน/สระ/ฟิตเนส) — มีใน `RESIDENTIAL_FEATURES` แต่โค้ดใช้เงื่อนไข `isHome` เลยซ่อนจากหมวดพาณิชย์ ซึ่งสไลด์ต้องการให้มี
- **เครื่องใช้ไฟฟ้า** — `appliances text[]` เก็บได้แค่ว่ามีอะไร แต่สไลด์ขอ "มีให้กี่เครื่อง" → ต้องเป็น `{ชนิด: จำนวน}` (jsonb)
- **ที่จอดรถ / เฟอร์นิเจอร์ / ห้องครัว / ห้องน้ำ** ของออฟฟิศ-โฮมออฟฟิศ — คอลัมน์มีอยู่แล้ว (`parking_spaces`, `furniture`, `kitchens`, `bathrooms`) แค่ปลดเงื่อนไขให้แสดงกับหมวดพาณิชย์
- **เอกสารสิทธิ์** — สไลด์ย้ำ `*ต้องมี` (สำเนาโฉนดหน้า-หลัง) สำหรับ บ้าน/คอนโด/ที่ดิน
  → **สรุปสุดท้ายคือไม่บังคับ** ตามที่ผู้ใช้สั่ง (หน้างานได้ไฟล์ทีหลัง) เหลือเป็นข้อความแนะนำ ดูหัวข้อ "พฤติกรรมที่ตัดสินใจไว้"

### ค. UX — ช่องว่างที่ใหญ่ที่สุด

[src/pages/FormPage.tsx](../src/pages/FormPage.tsx) ยาว 862 บรรทัด เป็นฟอร์มเดียวเลื่อนยาว (มี `form-card` เป็นหัวข้อ แต่ไม่มีสเต็ป)
ต้องทำเป็น wizard จริง: แถบ STEP 1–5 · ปุ่มถัดไป/ย้อนกลับ · validate เฉพาะสเต็ปนั้น · (ควรมี) save draft ระหว่างกรอก

### ง. กฎ conditional ที่สไลด์ระบุชัด

| เงื่อนไข | ให้แสดง | สถานะปัจจุบัน |
|---|---|---|
| `สำหรับ = ขาย` | ค่าใช้จ่ายวันโอนกรรมสิทธิ์ | มีฟิลด์ `transfer_fee` แต่ไม่ผูกเงื่อนไข |
| `สำหรับ = เช่า` | เงินประกัน, ค่าเช่าล่วงหน้า, ระยะเวลาสัญญา | แสดงตลอด ไม่ผูก `listing_type` |
| เช่าทั้งหลัง ยกเว้นที่อยู่อาศัย | ภาษีที่ดิน, หัก ณ ที่จ่าย, VAT | คุมด้วย `!isHome` แล้ว แต่ยังไม่มี VAT |
| ที่อยู่อาศัย | ไม่มีราคาต่อ ตร.ม. / ภาษี / VAT | ทำแล้ว |
| หมวดอุตสาหกรรม | โซน (Free Zone / กนอ. / DG) | `zones` แสดงเมื่อ `kind === 'general'` (กว้างเกินไป) |

## นัดติดตามในหน้าแก้ไขทรัพย์

เดิมแผงนัดติดตามอยู่แค่ในแผงรายละเอียด (กดดู) — พอเข้าหน้าแก้ไขแล้วหายไป ต้องย้อนกลับไปดู
ตอนนี้ย้าย `FollowUpSection` ออกมาเป็น [src/components/FollowUpSection.tsx](../src/components/FollowUpSection.tsx)
ใช้ร่วมกันทั้ง 2 ที่ · ในหน้าแก้ไขแสดงเป็นการ์ดท้ายหน้า (นัดค้าง + ประวัติ + ปุ่มปิดงาน + เพิ่มนัด)

- แสดงเฉพาะ **โหมดแก้ไข** (ทรัพย์ใหม่ยังไม่มี id ให้ผูกนัด) และเฉพาะ **แพ็กเกจ Pro** (เหมือน route `/followups`)
- ต้องเรนเดอร์ **นอก `<form>` ของฟอร์มทรัพย์** เพราะแผงนัดมีฟอร์มเพิ่มนัดของตัวเอง — ฟอร์มซ้อนฟอร์มเป็น HTML ที่ไม่ถูกต้อง
  (มีเทสต์คุมไว้: `document.querySelectorAll('form.form-wrap form').length === 0`)
- อยู่นอกแถบสเต็ป จึงเห็นได้จากทุกขั้น ไม่ต้องกดไปขั้นสุดท้าย

## บันทึกร่างอัตโนมัติ (draft)

[src/lib/draft.ts](../src/lib/draft.ts) + แถบแจ้งเตือนใน [FormPage](../src/pages/FormPage.tsx)

- เก็บใน **localStorage ของเครื่อง** (คีย์ `find_prop.draft.property.v1`) ไม่ส่งขึ้นเซิร์ฟเวอร์
- ทำงาน **เฉพาะตอนเพิ่มทรัพย์ใหม่** — ตอนแก้ไขทรัพย์เดิมไม่เก็บ (กันร่างเก่าทับข้อมูลใน DB)
- เขียนหลังหยุดพิมพ์ 800ms · เก็บทั้งค่าในฟอร์มและ**สเต็ปที่ค้างอยู่** · โชว์ "💾 เก็บร่างไว้ให้แล้ว HH:MM" ข้างปุ่ม
- เปิดหน้าใหม่แล้วเจอร่าง → **ไม่ยัดใส่ฟอร์มเงียบๆ** แต่ขึ้นแถบเหลืองให้เลือก "กรอกต่อจากร่าง" / "เริ่มใหม่ (ทิ้งร่าง)" · ระหว่างที่ยังไม่เลือก ระบบจะไม่เขียนร่างทับ (ไม่งั้นฟอร์มเปล่าจะลบร่างเดิมทันที)
- ล้างร่างเมื่อ: บันทึกเข้า DB สำเร็จ · กดทิ้งร่าง · ล้างฟอร์มกลับเป็นเปล่า
- localStorage ปิด (โหมดส่วนตัว) หรือเต็ม → ฟอร์มทำงานต่อได้ปกติ แค่ไม่มีร่าง
