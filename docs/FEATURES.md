# HOP — สรุปฟีเจอร์ทั้งระบบ

> 📄 **ฉบับละเอียดสำหรับส่งให้ลูกค้า/ทีมขาย:** [FEATURES.html](FEATURES.html) — เปิดในระบบที่ **/docs/features**
> (แยกทีละฟีเจอร์: ทำอะไรได้ · ใครใช้ได้ · อยู่ที่ไหน · ข้อจำกัด + ตารางสรุป ฟีเจอร์ × แพ็กเกจ × บทบาท)
> ไฟล์นี้เป็นสรุปสั้นสำหรับทีมพัฒนา (มีชื่อไฟล์ SQL/พาธประกอบ)

## 1. รายการทรัพย์ (หน้าหลัก)

- ค้นหาจากทุกฟิลด์ + ตัวกรอง: ประเภททรัพย์, เช่า/ขาย, จังหวัด, ช่วงราคา
- มือถือแสดงเป็นการ์ดอ่านง่าย, จอใหญ่เป็นตาราง — responsive ทุกขนาดจอ
- เปิดรายละเอียดครบทุกฟิลด์ พร้อมรูปภาพ แผนที่ และปุ่มลัด โทร / SMS / LINE / เปิด Google Maps
- รองรับ deep-link ตัวกรอง (เช่น จาก Dashboard จิ้มกราฟ → เปิดรายการพร้อมกรองให้เลย)

## 2. ฟอร์มเพิ่ม/แก้ไขทรัพย์

- **แบ่งเป็น 5 ขั้น** (ประเภททรัพย์ / ที่ตั้ง / รายละเอียด / ราคา / ลงภาพ) กดข้ามขั้นได้
  ตรวจช่องบังคับให้ทีละขั้น ไม่ต้องเลื่อนหาว่าตกอะไร — ดู [HOP Form spec](hop-form-spec.md)
- **ถามเฉพาะที่เกี่ยวกับทรัพย์นั้น** — เลือกหมวด+ประเภทแล้วขั้น "รายละเอียด" เปลี่ยนชุดคำถามให้เอง
  (โกดัง/โรงงานถามพื้นยกสูง-เครน-คอนเทนเนอร์ · บ้านถามทิศ-ห้องนอน-ห้องแม่บ้าน · ที่ดินถาม FAR/OSR/ติดถนน)
  และผูกกับ เช่า/ขาย (เช่า = เงินประกัน+VAT · ขาย = ค่าโอนกรรมสิทธิ์)
- **บันทึกร่างอัตโนมัติ** ระหว่างกรอก ปิดแอปแล้วเปิดใหม่ถามว่าจะกรอกต่อจากร่างไหม (เก็บในเครื่อง)
- ครบ 94 ฟิลด์ (ราคา พื้นที่ ค่าน้ำ-ค่าไฟ+ชำระกับใคร พื้นรับน้ำหนัก โซนสีผังเมือง ผู้ติดต่อ ฯลฯ)
- Dropdown แบบ "เลือกหรือพิมพ์เพิ่ม" และ multi-select (คุณสมบัติเด่น / การใช้งาน / โซนพิเศษ)
- เอกสารสิทธิ์: แนบรูป/PDF ได้หลายไฟล์ (ไม่บังคับ — โฉนดได้มาทีหลังก็แนบเพิ่มตอนแก้ไขได้)
- อัปโหลดรูปขึ้น Supabase Storage — **บนแอปมือถือถ่ายด้วยกล้องได้เลย** (ย่อขนาดก่อนอัปให้อัตโนมัติ)
- ปักพิกัดจากแผนที่ในฟอร์มได้โดยตรง

## 3. บันทึกทรัพย์ด้วยเสียง 🎤 + AI กรอกฟอร์ม

- กดพูดหน้างาน เล่ารายละเอียดทรัพย์รวดเดียว → AI แกะเป็นฟิลด์แล้วกรอกฟอร์มให้อัตโนมัติ
- เข้าใจตัวเลขที่พูดเป็นคำไทย เช่น "ค่าเช่าแปดหมื่นห้า" → 85,000
- แยกข้อมูลถูกช่อง: จุดเด่นเข้า "คุณสมบัติ" ไม่ปนกับหมายเหตุ, ไม่แต่งข้อมูลที่ไม่ได้พูด
- ถอดเสียงด้วย Web Speech API ในเบราว์เซอร์ (ฟรี, Chrome/Android แม่นสุด) — เบราว์เซอร์ที่ไม่รองรับจะซ่อนปุ่มให้เอง

## 4. แผนที่รวมทรัพย์

- ปักหมุดทรัพย์ทั้งหมดที่มีพิกัดบนแผนที่เดียว (Leaflet/OpenStreetMap)
- **หมุดแยกตามประเภททรัพย์:** สีประจำประเภท + ไอคอนในหัวหมุด (บ้าน/คอนโด/ออฟฟิศ/โฮมออฟฟิศ/โชว์รูม/โกดัง/โรงงาน/ที่ดิน) — ใช้สีคู่กับรูปเสมอ อ่านออกแม้ตาบอดสี
- **แถบสี (legend) ล่างแผนที่:** บอกว่าสีไหนคือประเภทไหน + จำนวน — แตะเพื่อกรองดูเฉพาะประเภทนั้น มีชิพ "ทั้งหมด" กดกลับ
- **ปุ่มตำแหน่งฉัน:** กระโดดไปตำแหน่งปัจจุบัน (บนแอปใช้ GPS ของเครื่องแบบ native แม่นกว่า)
- Popup สรุปย่อ + กดเปิดรายละเอียดเต็ม
- หมุดร่างสีม่วงสำหรับกำหนดตำแหน่งทรัพย์ใหม่

## 5. แผนเยี่ยมชม (จัดรูทพาลูกค้าดูทรัพย์)

- สร้างแผนต่อลูกค้า เลือกทรัพย์เป็นจุดแวะ จัดลำดับก่อน-หลังได้
- เปิดเส้นทางใน Google Maps ทุกจุดแวะในคลิกเดียว — เริ่มนำทางจากตำแหน่งปัจจุบัน
- **แจ้งเตือนล่วงหน้า (push บนแอปมือถือ):** ทุกเช้าเตือนสมาชิกที่มีแผนเยี่ยมชมของวันพรุ่งนี้ — แตะแจ้งเตือนเปิดหน้าแผนได้ทันที
- **AI จับคู่ requirement ใหม่:** ลูกค้าเปลี่ยนความต้องการกลางทาง (พิมพ์หรือพูดใส่) → AI สแกนทรัพย์ทั้งระบบ แนะนำตัวที่ตรง พร้อมชี้ว่าจุดแวะเดิมตัวไหนไม่ตรงแล้ว → กดเพิ่มเข้ารูทได้ทันที

## 6. นัดติดตาม (ฟีเจอร์ Pro)

- ตั้งนัดว่าต้องตามเรื่องอะไร ครบกำหนดวันไหน ผูกกับทรัพย์ได้ (หรือไม่ผูกก็ได้)
- แท็บ **ต้องทำ / ที่จะถึง / เสร็จแล้ว** — เกินกำหนดขึ้นสีแดง, ครบกำหนดวันนี้ขึ้นสีม่วง
- ปิดนัดแล้ว**พิมพ์ผลที่ได้** ("โทรไม่รับ", "เจ้าของยอมลด 5%") เลือกได้ว่า *จบเรื่อง* หรือ *ตามต่อ*
  (สร้างนัดรอบถัดไปให้เลย) — ประวัติทุกรอบเก็บไว้ ไม่หาย
- ปุ่ม **บันทึกผลเลย** สำหรับสิ่งที่ทำไปแล้ว ไม่ต้องตั้งนัดก่อน
- **แจ้งเตือนเข้ามือถือทั้งทีม 07:00 น.** ของวันครบกำหนด (`api/push-cron.js` → FCM)
- ในหน้ารายละเอียดทรัพย์มีแผงนัดติดตามของทรัพย์นั้นโดยเฉพาะ + ปุ่ม **ปิดงาน**
  (มีคนเช่าแล้ว / ขายแล้ว) ซึ่งปิดนัดค้างทั้งหมดพร้อมลงประวัติ และเปิดงานใหม่ได้ถ้าดีลล่ม
- ทรัพย์ที่ปิดงานแล้วมีป้ายกำกับในรายการ และผู้ช่วย AI จะไม่เสนอว่ายังว่าง

## 7. ชอร์ตลิสต์เปรียบเทียบ (เสนอลูกค้า)

- เลือกทรัพย์ 2–4 รายการ เทียบสเปกเป็นตารางเรียงข้าง
- AI เขียนบทวิเคราะห์ จุดเด่น / ข้อควรพิจารณา / คำแนะนำ ประกอบการตัดสินใจ
- พิมพ์ / บันทึก PDF เป็นเอกสารเปรียบเทียบหัวกระดาษ HOP (แนวนอน A4) ส่งลูกค้าได้ทันที — บนแอปสั่งพิมพ์/เซฟ PDF ผ่านระบบพิมพ์ของเครื่องได้เลย
- เปิดจากหน้ารายการ หรือสั่งผ่านผู้ช่วย AI ก็ได้

## 8. นำเข้าข้อมูลจาก Excel / CSV

- อัปโหลดไฟล์ (เช่น export จาก AppSheet / Google Sheets เดิม) แบบ 3 ขั้นตอน: อัปโหลด → ตรวจ/จับคู่คอลัมน์ → นำเข้า
- จับคู่หัวคอลัมน์กับฟิลด์อัตโนมัติ (รู้จักชื่อไทยหลายแบบ), แก้การจับคู่เองได้
- รองรับวันที่ พ.ศ. / วันที่แบบ Excel / เลขมีคอมมา — แปลงให้ถูกต้อง
- ตรวจรหัสทรัพย์ซ้ำ เลือก "ข้าม" หรือ "อัปเดตทับ" ได้ + มีเทมเพลต CSV ให้ดาวน์โหลด

## 9. Dashboard สรุปภาพรวม

- ตัวเลขพอร์ต: มูลค่าเช่า/ขายรวม, ทรัพย์ใหม่เดือนนี้ + sparkline ย้อนหลัง 6 เดือน
- นัดเยี่ยมชมที่ใกล้ถึง พร้อมปุ่มนำทาง
- สัดส่วนประเภททรัพย์ / เช่า-ขาย (แตะกราฟ → เปิดหน้ารายการพร้อมตัวกรอง)
- ทำเลยอดนิยม (Top อำเภอ)
- ค่าเช่าเฉลี่ยต่อ ตร.ม. แยกตามประเภท + ชี้ทรัพย์ที่ถูก/แพงกว่าค่าเฉลี่ยกลุ่มอย่างมีนัย
- สุขภาพข้อมูล: ทรัพย์ที่ยังไม่มีรูป / พิกัด / ราคา / เบอร์ติดต่อ / ข้อมูลค้างเก่าเกิน 90 วัน
- **AI วิเคราะห์พอร์ตรายวัน:** จุดแข็งของพอร์ต, demand ที่ยังไม่มีของ, ทรัพย์ที่ควรเร่งนำเสนอ (แคชวันละครั้ง)

## 10. ผู้ช่วย AI (แชทลอยทุกหน้า) ✨

- ถามข้อมูลทรัพย์/แผนเยี่ยมชมของทีมเองเป็นภาษาพูด เช่น "โกดังแถวบางพลีงบไม่เกินแสนมีไหม" → ตอบจากข้อมูลจริงพร้อมการ์ดทรัพย์กดดูต่อได้ ไม่มีข้อมูลก็บอกตรงๆ ไม่มโน
- สั่งงานผ่านแชทได้: เพิ่ม/ถอดทรัพย์จากรูท, สร้างแผนเยี่ยมชม, เปิดหน้าเปรียบเทียบ — ทุกคำสั่งมีปุ่มยืนยันก่อนทำจริง
- พูดถามด้วยไมค์ + โหมดอ่านคำตอบออกเสียง (เหมาะตอนขับรถ)
- จำบทสนทนาไว้ในเครื่อง เปิดต่อจากเดิมได้

## 11. ประวัติการใช้งาน (audit trail)

- บันทึกด้วย **trigger ในฐานข้อมูล** ([supabase/logs-triggers.sql](../supabase/logs-triggers.sql)) →
  แก้ผ่านเว็บ, แอป, SQL Editor, REST API หรือสคริปต์ ก็ถูกบันทึกเหมือนกันหมด ไม่มีช่องหลุด
- ครอบคลุม: ทรัพย์ (เพิ่ม/แก้ไข·ระบุฟิลด์ที่เปลี่ยน/ลบ) · **ปิดงาน-เปิดงาน** · นัดติดตาม (ตั้ง/ปิด+ผล/แก้/ลบ) ·
  แผนเยี่ยมชม (สร้าง/แก้รูท/ลบ) · ทีมและสิทธิ์ (เพิ่ม/แก้บทบาท/เปิด-ปิด/ถอด) · บทบาท-สถานะบัญชี ·
  องค์กรและแพ็กเกจ · **การสวมสิทธิ์องค์กรของ super admin** · สลับองค์กร · นำเข้า Excel · การใช้ AI
- ตารางไม่มี policy `update`/`delete` → **แก้ย้อนหลังไม่ได้** เป็นหลักฐานถาวร
- ระบุที่มาให้ด้วย: `via = app` (ทำผ่านแอป) หรือ `via = sql` (ทำผ่าน SQL/สคริปต์ — ชื่อผู้ทำขึ้นว่า "ระบบ/SQL")
- ไม่เก็บการ "อ่าน/ค้นหา/ส่งออก" (เจตนา — ไม่งั้น log ท่วมและช้า) · เข้าสู่ระบบ/ออกดูได้ที่ Supabase → Authentication → Logs
- ดูได้เฉพาะแอดมินองค์กรและ super admin (บังคับด้วย RLS) · กรองตามกลุ่มการกระทำ/ผู้ใช้/ช่วงเวลา

## 12. ทีมและสิทธิ์การใช้งาน

- ล็อกอินด้วยอีเมล (Supabase Auth) หรือ Google — ข้อมูลแยกตามองค์กรด้วย Row Level Security ทั้งระบบ
- **จำการเข้าสู่ระบบในเครื่องนี้** (ติ๊กไว้เป็นค่าเริ่มต้น): ติ๊ก = session ใน `localStorage` ปิดเบราว์เซอร์แล้วยังล็อกอินอยู่ · ไม่ติ๊ก = `sessionStorage` ปิดแท็บ/เบราว์เซอร์แล้วออกจากระบบเอง (เครื่องสาธารณะ) — สลับ storage ด้วย adapter ใน `src/lib/authStorage.ts` และ**ล้าง token ของอีกฝั่งทิ้งทุกครั้ง** ไม่ให้ค้างในเครื่อง
- **ลืมรหัสผ่าน:** ลิงก์ "ลืมรหัสผ่าน?" → ส่งอีเมลลิงก์ตั้งรหัสใหม่ (`resetPasswordForEmail` → `/#/login?reset=1`) · กดลิงก์แล้วแอปดักเหตุการณ์ `PASSWORD_RECOVERY` → **บังคับตั้งรหัสใหม่ก่อนเข้าแอป** (`ResetPasswordScreen`) · ไม่บอกว่าอีเมลมีในระบบหรือไม่ (กัน account enumeration) · ⚠️ ต้องใส่ Redirect URL ใน Supabase → Authentication → URL Configuration
- **บทบาท 8 ระดับ:** Owner · Manager · Associate · Analyst · Survey · Temporary · Social Media Admin · Trainee — คุมทั้งการเห็นแถว (ทั้งองค์กร / เฉพาะเขตที่กำหนด / เฉพาะของตัวเอง), **ปิดข้อมูลระดับฟิลด์** (ข้อมูลติดต่อเจ้าของทรัพย์ · บ้านเลขที่/เลขที่ห้อง · พิกัด/ลิงก์แผนที่ ของคนอื่น), สิทธิ์แก้/ลบ (Manager ลบทรัพย์ของ Owner ไม่ได้), บทบาทดูล้วน และการนำข้อมูลออก (Owner เท่านั้น) — ดู [roles-spec.md](roles-spec.md) · ติดตั้งด้วย `supabase/roles.sql`
- **หน้าทีม (Owner):** เชิญลูกทีมด้วยลิงก์พร้อมเลือกบทบาท, เปลี่ยนบทบาทรายคน, กำหนด "เขต" (จังหวัด/อำเภอ) ให้ Survey/Temporary, เปลี่ยนชื่อองค์กร
- **นำข้อมูลออก CSV (Owner เท่านั้น):** นำออกรายการที่กรองอยู่ หัวคอลัมน์เป็นป้ายไทยชุดเดียวกับการนำเข้า → นำเข้ากลับได้ทันที
- **ที่นั่งทีม (seats):** แพ็กเกจแถมที่นั่งตามระดับ (ค่าเริ่มต้น Basic 3/5/10 · Pro 5/10/20 · Free 1 · Enterprise ไม่จำกัด) — **super admin ปรับจำนวนที่นั่งต่อแพ็กเกจได้จากหน้า Super Admin** มีผลทันทีไม่ต้อง deploy · เต็มแล้วซื้อเพิ่มรายที่นั่งได้ (฿290/ที่นั่ง/เดือน) หน้าทีมโชว์ "ใช้ x จาก y ที่นั่ง" · ลูกทีมไม่ต้องจ่ายเอง องค์กรจ่ายก้อนเดียว — ดู [seats-pricing.md](seats-pricing.md) · ติดตั้งด้วย `supabase/seats.sql` + `seats-config.sql`
- **ทดลองใช้ 14 วัน = ไม่จำกัดที่นั่ง:** เชิญทีมทั้งบริษัทมาลองได้เลย พอหมดช่วงทดลองโควตากลับมาเป็นของแพ็กเกจที่ซื้อ ส่วนที่เกินมีแถบบอกยอดที่ต้องจ่าย + ปุ่มซื้อที่นั่งที่กรอกจำนวนไว้ให้ — **ไม่มีใครถูกนำออกจากองค์กร** แค่เชิญคนใหม่ไม่ได้จนกว่าที่นั่งจะพอ
- **หน้า Super Admin (เจ้าของระบบ):** เห็นทุกองค์กร จำนวนสมาชิก/ทรัพย์, ตั้งแพ็กเกจ free/pro/enterprise และวันหมดอายุ
- **มุมมอง super โหมดภาพรวม:** ป้ายชื่อองค์กรบนทรัพย์ + dropdown กรององค์กรครบทุกหน้า (รายการ/แผนที่/สรุปภาพรวม/แผนเยี่ยมชม/Super Admin) — Dashboard และ AI insight คำนวณตามองค์กรที่เลือก
- **super สร้าง/แก้ทรัพย์แทนลูกค้าได้จากโหมดภาพรวม:** ฟอร์มมีช่อง "องค์กรเจ้าของทรัพย์" บังคับเลือกก่อนบันทึก (ติดตั้งด้วย `supabase/super-write.sql`)
- **สวมสิทธิ์องค์กร (impersonation):** super คลิกชื่อองค์กรในหน้า Super Admin → ทำงานเสมือนสมาชิกองค์กรนั้น (เพิ่ม/แก้/นำเข้าข้อมูลแทนลูกค้าได้จริง) มีแถบเตือนสีเหลือง + ปุ่ม "ออกจากสิทธิ์" ตลอดเวลา — ติดตั้งด้วย `supabase/impersonate.sql`
- **ประวัติการใช้งาน (เฉพาะแอดมิน):** บันทึกอัตโนมัติว่าใครทำอะไรเมื่อไหร่ — เพิ่ม/แก้/ลบทรัพย์, แผนเยี่ยมชม, นำเข้าไฟล์, การใช้ AI — กรองตามประเภท/ค้นหาชื่อคนได้ ล็อกด้วย RLS: สมาชิกทั่วไปเปิดดูไม่ได้ และแก้/ลบย้อนหลังไม่ได้ (audit trail ถาวร)

- **เอกสารนำเสนอนักลงทุน ([INVESTOR.html](INVESTOR.html)):** เอกสารภายใน — **ไม่ถูกก๊อปขึ้น production** (กันด้วย `PRIVATE_DOCS` ใน `vite.config.ts` + ไม่มี rewrite ใน `vercel.json` · `npm run test:docs` เช็คทั้ง 3 ชั้น) เปิดโดยดับเบิลคลิกไฟล์ (self-contained ใช้ออฟไลน์ได้) หรือที่ `/docs/investor` ตอนรัน dev
- **คู่มือใช้งานอยู่ในระบบ:** เมนูบัญชี (มุมขวาบน) → "คู่มือใช้งาน (ฉบับเต็ม)" และการ์ดในหน้าโปรไฟล์ → เปิด **/docs/training** ([TRAINING.html](TRAINING.html)) · หน้า Super Admin มีลิงก์ **/docs/system** ([SYSTEM.html](SYSTEM.html)) เอกสารเชิงเทคนิคสำหรับทีมงาน — URL ไม่โชว์ `.html` (rewrite ใน `vercel.json`) · ไฟล์อยู่ใน `docs/` ที่เดียว ตอน build ก๊อปไป `dist/docs/` เป็นชื่อพิมพ์เล็กอัตโนมัติ (ไปกับเว็บและแอปมือถือ)

## 13. แอปมือถือ native (Android + iOS)

- **แอปจริงจากโค้ดเว็บชุดเดียว** — ห่อด้วย Capacitor ออกได้ทั้ง Android และ iOS ลง Store ได้
- **กล้อง** ถ่ายรูปทรัพย์หน้างาน · **GPS native** ปุ่มตำแหน่งฉันบนแผนที่ · **push** เตือนแผนเยี่ยมชม
- **พิมพ์ / บันทึก PDF** เอกสารเปรียบเทียบผ่านระบบพิมพ์ของเครื่อง
- **อัปเดตเอง ไม่ต้องโหลดแอปใหม่:** แก้ฝั่งเว็บแล้วแอปตามอัตโนมัติ (live-update); งานที่แตะโค้ด native จะเด้งแถบ "เวอร์ชันใหม่พร้อมติดตั้ง" ในแอปเอง (Android — iOS อัปผ่าน App Store/TestFlight)
- **แจก APK ตรงได้** ผ่านลิงก์ถาวรบน GitHub Releases (ไม่ต้องผ่าน Store ตอนนำร่อง) — สร้างอัตโนมัติทุกครั้งที่ push โดย GitHub Actions
- ยังติดตั้งเป็น **PWA** จากเบราว์เซอร์ได้เหมือนเดิม — ใช้งาน offline ได้ (แคชแผนที่/ข้อมูล/รูป)
- ออกแบบ mobile-first: เมนูล่างแบบแอป, ตารางกลายเป็นการ์ด, ปุ่ม/ฟอนต์ขนาดเหมาะกับนิ้ว, รองรับจอ edge-to-edge (Android 15 / Dynamic Island)

## สถาปัตยกรรมและความปลอดภัย

- **AI ทุกฟีเจอร์เรียกผ่าน proxy ฝั่งเซิร์ฟเวอร์** (`api/ai.js` บน Vercel) — คีย์ LLM อยู่ใน environment variable ฝั่งเซิร์ฟเวอร์เท่านั้น ไม่มีทางหลุดจากหน้าเว็บ และตรวจว่าเป็นผู้ใช้ที่ล็อกอินจริงก่อนทุกครั้ง
- **LLM รันบนเครื่องของเราเอง** (gemma-4-12b บน vLLM, GPU RTX 5060 Ti) — ข้อมูลทรัพย์ไม่ออกไปเซิร์ฟเวอร์ AI ภายนอก และไม่มีค่าใช้จ่ายรายเดือน
- ก่อนส่งให้ AI ระบบคัดเฉพาะทรัพย์ที่เกี่ยวข้องกับคำถาม (relevance filter) — ตอบแม่นขึ้นและเร็วขึ้น
- Row Level Security ทุกตาราง: แต่ละองค์กรเห็นเฉพาะข้อมูลตัวเอง
- **แอปมือถืออัปเดตปลอดภัย:** live-update ตรวจเวอร์ชันด้วยเวลา build (กันโดนดึงลงเวอร์ชันเก่า) + bundle ที่พังจะย้อนกลับตัวเดิมอัตโนมัติ; APK เซ็นด้วยกุญแจกลางคงที่ทุกรอบ build จึงติดตั้งทับกันได้เสมอ
- **push แจ้งเตือน:** เก็บ device token ต่อผู้ใช้/องค์กร (RLS: เขียนได้เฉพาะของตัวเอง), ยิงจาก Vercel Cron ผ่าน FCM — คีย์ service account อยู่ใน env ฝั่งเซิร์ฟเวอร์เท่านั้น
